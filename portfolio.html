The English Revisionator

This is a project I had planned - will probably never come to life, idk.

I made a whole wireframe and stuff so would be great to actually develop some day.

As for what it actually is, this will hopefully be a revision website for English Literature A-level. It was originally supposed to be a desktop app, but a website is probably more in scope for me.

The homepage has a menu which leads to individual pages on each text (Othello, Streetcar, Gatsby, Handmaid's and more). Each text page will contain a menu for different modes. So far I have, Quote the quote! and Best fitting quote! in mind. Quote the quote! will be a Sporcle-inspired quiz-ish, where you have to enter a quote with its textual reference. These will appear in the list (like the name the countries quiz) if the input is correct. Best fitting quote! will be essentially a randomised set of themes/characters/questions where the user will have to input a quote that fits best. This could be a large data set, or more efficiently, an AI agent. (but my skills are nowhere near that level so idk)

Improvements to this idea: I could add a timer feature to QTQ. And then ofc the fun stuff, like customisation and making accounts etc. Leaderboards - gamification
